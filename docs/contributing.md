# Guía de Contribución

## Objetivo

Este documento establece las pautas que deben seguir los integrantes del equipo para contribuir al desarrollo del proyecto AgroValle Connect, garantizando una colaboración organizada y manteniendo la calidad del software.

---

## Flujo de Trabajo

1. Actualizar la rama `develop` antes de iniciar una nueva tarea.
2. Crear una rama específica para la funcionalidad o actividad asignada.
3. Realizar los cambios correspondientes en la rama de trabajo.
4. Ejecutar las pruebas necesarias antes de realizar un commit.
5. Crear un Pull Request hacia la rama `develop`.
6. Atender las observaciones realizadas durante la revisión.
7. Integrar los cambios una vez aprobados.

---

## Convención de Ramas

Se recomienda utilizar nombres descriptivos para las ramas:

- `feature/nombre-funcionalidad`
- `fix/nombre-correccion`
- `docs/nombre-documentacion`
- `refactor/nombre-refactorizacion`
