# Definition of Done - AgroValle Connect

## 1. Propósito del contrato DoD
En el presente acuerdo Definition of Done (DoD) se establecen las condiciones que se deben de cumplir 
para que una historia de caso de usuario pueda considerarse completamente terminada y lista para ser entregada.

Estableciendo y garantizando que las funcionalidades desarrolladas cumplan los criterios de aceptación, calidad, pruebas y documentacion correspondiente.


---

## 2. Checklist de calidad

En el presente proyecto se considerara que una historia de usuario esta terminada cuando cumple los siguientes criterios de calidad:


### Funcionalidad

- [ ] La funcionalidad fue implementada de acuerdo con la historia de usuario.
- [ ] Se cumplen todos los criterios definidos en el HU.
- [ ] Las validaciones necesarias fueron implementadas.
- [ ] La funcionalidad responde correctamente a los casos esperados.

### Pruebas

- [ ] La funcionalidad fue probada antes de considerarse terminada.
- [ ] Se verificaron los casos principales de uso.
- [ ] Se corrigieron los errores encontrados durante las pruebas.
- [ ] No existen errores críticos conocidos que impidan utilizar la funcionalidad.

### Código

- [ ] El código compila y funciona correctamente.
- [ ] El código sigue la estructura y reglas establecidas para el proyecto.
- [ ] No se dejaron fragmentos de código innecesarios o sin utilizar.
- [ ] El código fue revisado por al menos 2 integrantes del equipo.

### Base de datos

- [ ] La funcionalidad realiza correctamente las operaciones necesarias sobre la base de datos.
- [ ] Los datos se almacenan y consultan correctamente.
- [ ] Se respetan las relaciones y restricciones definidas en la base de datos.
- [ ] No se generan registros inconsistentes como resultado de la funcionalidad.

### Documentación

- [ ] La historia de usuario y sus criterios de aceptación están definidos.
- [ ] Se actualizó la documentación del proyecto cuando fue necesario.
- [ ] Los cambios realizados fueron registrados en el repositorio agrovalle.

### Integración

- [ ] La funcionalidad fue integrada correctamente al proyecto.
- [ ] Los cambios fueron subidos al repositorio correspondiente.
- [ ] La integración no afecta negativamente las funcionalidades existentes.
