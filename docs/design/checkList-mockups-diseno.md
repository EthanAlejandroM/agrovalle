# CheckList de calidad para Mockups y UX/UI
[ ] El proceso de registro permite diferenciar de forma clara si el usuario se registra como Agricultor o como Comprador.

[ ] El registro solicita únicamente los datos esenciales para empezar evitando formularios extensos que desanimen al usuario.

[ ] El mockup del Login incluye una opción accesible y clara para la recuperación de contraseña

[ ] El panel permite al agricultor visualizar rápidamente sus productos publicados, el stock disponible y sus precios.

[ ] El botón para agregar un nuevo producto destaca y la pantalla de creación es fácil de diligenciar desde cualquier dispositivo.

[ ] El agricultor tiene una sección clara donde pueda ver las solicitudes de compra pendientes, confirmadas o entregadas.

[ ] El comprador visualiza un catálogo donde se resalta las fotos de los productos, nombres, precios y la ubicación del agricultor *municipio del Valle*.

[ ] El comprador dispone de filtros útiles para buscar por categoría de alimento o por municipio.

[ ] El flujo hacia la compra muestra de forma transparente el desglose de productos, cantidades, subtotales y datos de entrega.

[ ] Se mantiene la misma paleta de colores, tipografías, estilo de botones e iconografía a lo largo de los módulos diseñados

[ ] La barra de navegación o menú principal está ubicada en el mismo lugar y permite moverse fácilmente entre las secciones principales de la app.

[ ] Los tamaños de texto, contrastes de color y áreas de toque de los botones son adecuados para pantallas móviles y computadores.

[ ] Se representó cómo se ven las pantallas cuando aún no hay datos registrados, panel de comprador sin pedidos o panel de agricultor sin productos cargados.
